# The Joy of Painting — A Bob Ross Experience

A single-file microsite tribute to _The Joy of Painting_.

The whole thing — markup, styles, and interaction — lives in one `index.html` (~2,200 lines), as an exercise in how much polish a zero-dependency page can carry.

## Details

- **Paint-inspired design system** — CSS custom properties named for the medium (`--canvas-cream`, `--canvas-warm`) drive a warm, canvas-textured palette
- **Episode browser** — season pills, a load-more pattern, and radio-style controls, all in vanilla JS
- **Motion** — nine hand-tuned `@keyframes` animations, no animation library

## Running locally

Open `index.html` in a browser. That's it — no build, no dependencies.
